# 音效与特效动画增强长期需求

## 状态

- 当前状态：已登记，待分阶段实施
- 创建日期：2026-05-01
- 关联任务：
  - `tasks/backlog/2026-05-01-enhance-game-audio.md`
  - `tasks/backlog/2026-05-01-enhance-vfx-animation.md`

## 背景

当前项目已经具备战略模拟、地图渲染、AI 决策和基础动画体系，但音效与特效动画仍偏原型阶段。为了让《Silicon Hegemony》的反馈更有沉浸感，需要建立一条长期的音画增强路线。

用户提出长需求：

1. 增强音效。
2. 增强特效动画。
3. 可尝试使用图像生成制作游戏素材，使用音频生成制作音效素材。

## 目标

- 建立统一音效系统，让行动、战斗、赛博、建设、外交、危机和 UI 操作都有清晰反馈。
- 建立统一特效动画系统，让地图事件更易读、更有冲击力。
- 支持后续引入生成式素材，包括：
  - 图像生成：特效贴图、粒子 sprite、图标、事件插画、UI 装饰素材。
  - 音频生成：行动音效、环境音、警报声、赛博音效、战斗冲击声。
- 先用可控、轻量、可回退的方式接入，不阻塞当前 GPU globe 迁移主线。

## 范围

### 音效增强

- UI 音效：按钮、切换地图模式、打开/关闭面板、错误提示。
- 行动音效：招募、移动、攻击、建设、宣传、游说、侦察、谍报、赛博攻击。
- 系统音效：回合开始/结束、AI 思考完成、危机触发、势力灭亡、胜利提示。
- 地图音效：hover、选择领土、前线变化、补给短缺提示。
- 音频管理：音量、静音、分组、节流、防止重复爆音。

### 特效动画增强

- 战斗：冲击波、火光、弹道、前线闪烁。
- 移动：路径线、军队迁移尾迹、补给运输流动。
- 建设：工厂/防御/宣传塔建造完成反馈。
- 赛博：节点脉冲、扫描波、黑客攻击电流/故障效果。
- 外交：条约建立、关系破裂、联盟形成。
- 全球危机：地图级警报、范围扩散、环境滤镜。
- 地图模式：政治/经济/军事/补给/赛博模式切换过渡。

## 素材生成策略

### 图像生成

可用于：

- 粒子贴图：光点、爆闪、烟雾、电弧、扫描波纹。
- UI 图标：行动类型、危机类型、资源类型。
- 事件插图：全球危机、AI 宣言、战报封面。

约束：

- 生成素材必须进入 `public/assets/` 或 `src/assets/` 并记录来源。
- 需要统一尺寸、透明背景、命名规范和压缩策略。
- 不直接把生成结果散落到组件里。

### 音频生成

当前环境没有可调用的音频生成工具，因此第一阶段不依赖音频生成接口。后续如果可用，应生成短音效并统一归档。

替代方案：

- 第一阶段使用 Web Audio API 合成程序化音效。
- 可用简单 oscillator、noise、filter、envelope 合成 UI、赛博、警报、冲击类音效。
- 若未来接入音频生成，则将生成素材整理为短 `wav` / `ogg` / `mp3` 文件并进入音频资源清单。

## 分阶段计划

### 第一阶段：音效系统基础

- 新增 `AudioManager` 或等价服务。
- 支持音量、静音、音效分组和防抖。
- 用 Web Audio API 生成第一批程序化音效。
- 在关键行动和 UI 操作中触发音效。

### 第二阶段：特效动画基础

- 梳理现有 `AnimationLayer`。
- 为攻击、移动、建设、赛博攻击增加更明确的地图反馈。
- 当前 GPU globe 迁移期间，特效层需要同时考虑 Pixi fallback 与 GPU globe 的目标架构。

### 第三阶段：生成式素材引入

- 使用图像生成制作粒子贴图、事件插图和行动图标。
- 若有音频生成能力，制作统一风格音效包。
- 建立 `docs/assets/` 或 `docs/reports/` 下的素材来源记录。

### 第四阶段：统一演出系统

- 把行动结果、日志、音效、地图特效和 UI 提示统一成事件驱动的演出 pipeline。
- 支持不同地图模式下的特效变体。
- 支持低性能设备降级。

## 风险

- 音效过多可能造成疲劳，需要节流和分组控制。
- 生成素材风格可能不统一，需要先定义艺术方向。
- 特效动画如果直接叠加在旧 Pixi 和新 GPU globe 两套地图上，容易重复开发。
- 音频生成工具当前不可用，不能把它作为近期硬依赖。
- 大量贴图和音频资源会增加包体，需要压缩和懒加载策略。

## 验收标准

- 已有本地需求文档和 backlog 任务。
- 音效与特效分别有独立任务，避免遗漏。
- 后续实施时，每个阶段都需要补充素材清单、触发点清单和验证记录。
- 若使用生成式素材，必须记录生成用途、文件路径和后处理结果。
