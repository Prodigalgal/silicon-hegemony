# 增强特效动画任务

## 状态

- 当前状态：未开始
- 创建日期：2026-05-01
- 关联需求：`docs/requirements/2026-05-01-audio-and-vfx-enhancement-roadmap.md`

## 目标

增强地图和 UI 的特效动画表现，让战斗、移动、建设、赛博、外交和危机事件更直观、更有冲击力。

## 待办清单

- [ ] 盘点现有 `AnimationLayer`、`WeatherLayer` 和地图事件队列。
- [ ] 定义特效类型：攻击、移动、建设、赛博、外交、危机、地图模式切换。
- [ ] 设计特效事件 schema，避免动画逻辑散落在业务代码里。
- [ ] 增强攻击动画：冲击波、闪光、前线反馈。
- [ ] 增强移动动画：路径尾迹、流动线。
- [ ] 增强赛博动画：扫描波、节点脉冲、电弧/故障效果。
- [ ] 增强建设动画：建造完成、设施升级反馈。
- [ ] 使用图像生成制作粒子贴图、特效 sprite 或事件插图。
- [ ] 补充低性能设备降级策略。
- [ ] 补充测试/验证记录。

## 素材策略

- 可调用图像生成制作透明背景粒子贴图、冲击波、扫描波、电弧、烟雾、事件插图等。
- 所有生成素材需统一归档，记录用途、路径、生成提示和后处理结果。
- 特效贴图需要控制尺寸和数量，避免包体失控。

## 验收标准

- 行动事件和地图事件有更清楚的视觉反馈。
- 特效动画不阻塞回合推进。
- 动画层能适配当前 GPU globe 迁移方向。
- 低性能设备可降级或关闭高成本特效。
