# 增强游戏音效任务

## 状态

- 当前状态：未开始
- 创建日期：2026-05-01
- 关联需求：`docs/requirements/2026-05-01-audio-and-vfx-enhancement-roadmap.md`

## 目标

建立统一游戏音效系统，为 UI、行动、战斗、赛博、建设、外交、危机和回合推进提供清晰反馈。

## 待办清单

- [ ] 盘点当前已有音频资源和触发点。
- [ ] 设计音效分组：UI、行动、战斗、赛博、系统、危机。
- [ ] 新增音频管理模块，支持音量、静音、节流和重复播放控制。
- [ ] 第一阶段使用 Web Audio API 合成程序化音效。
- [ ] 接入 UI 按钮、地图模式切换、领土选择、回合推进音效。
- [ ] 接入行动音效：移动、攻击、建设、宣传、侦察、赛博攻击。
- [ ] 如后续有音频生成工具，生成并归档短音效素材。
- [ ] 补充测试/验证记录。

## 素材策略

- 当前无可调用音频生成工具，先用程序化音效。
- 后续可生成 `wav` / `ogg` / `mp3` 短音效。
- 生成或新增素材需记录路径、用途、来源和压缩情况。

## 验收标准

- 音效系统可统一调用，不散落在组件里。
- 用户可静音或调节音量。
- 高频事件有节流，避免爆音。
- 关键游戏事件有可辨识音效反馈。
