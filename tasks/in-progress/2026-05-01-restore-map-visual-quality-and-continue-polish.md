## 背景

用户反馈当前这一版地图没有上一版做得好。上一版 Pixi 地图在区域描边、游戏状态表达、前线/链接/图标/天气等图层方面更完整；当前 GPU globe 版本虽然验证了长期方向，但仍处于基础阶段，行政区填充、命中和边界已经接入，但整体视觉 polish、信息层和旧图层迁移尚未完成。

## 目标

1. 先恢复默认地图体验质量，避免 GPU 实验路径影响当前可玩性。
2. 保留 GPU globe 作为实验/后续演进路径，不删除已有成果。
3. 梳理并补齐当前地图遗漏事项，继续推进项目完善。
4. 做浏览器验证，确认默认地图体验稳定。

## 本轮方案

- 默认地图渲染切回 Pixi 路径，恢复上一版更完整的地图体验。
- GPU globe 保留在代码中，通过显式开关启用，作为后续实验路径。
- 增强文档记录：GPU globe 需要继续补齐视觉质量、图层迁移、精确 picking、LOD 数据管线后再作为默认地图。
- 如时间允许，补充一个开发开关，便于后续比较 Pixi 与 GPU globe。

## 风险

- 直接删除 GPU globe 会浪费长期方案成果，因此本轮不删除。
- Pixi 默认路径仍会开启旧 2D 投影，10m 数据下可能有性能压力，但当前视觉和玩法完整度更高。
- 后续需要继续把 GPU globe 的视觉质量补到 Pixi 水平，再切回默认。

## 验收标准

- 默认地图恢复上一版 Pixi 视觉和信息层体验。
- GPU globe 可保留为实验路径，不影响默认玩法。
- `npm run lint`、`npm run build`、`npm run test` 至少通过。
- 浏览器 smoke 验证通过。
- 任务和需求文档回写当前结论、验证结果和后续遗漏事项。
